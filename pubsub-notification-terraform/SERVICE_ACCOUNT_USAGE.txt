================================================================================
SERVICE ACCOUNT USAGE GUIDE
================================================================================

After running `terraform apply`, a service account will be created with 
permissions to upload and download files from both GCS buckets:
  - Main bucket: test-dp-gcspubsub-bucket
  - Landing bucket: test-dp-gcspubsub-bucket-landing

--------------------------------------------------------------------------------
1. AUTHENTICATION
--------------------------------------------------------------------------------

The service account key is saved in the same directory as:
  ./service-account-key.json

Set the environment variable to use this key:

  export GOOGLE_APPLICATION_CREDENTIALS="$(pwd)/service-account-key.json"

Or activate with gcloud:

  gcloud auth activate-service-account --key-file=./service-account-key.json

--------------------------------------------------------------------------------
2. UPLOAD FILES TO BUCKETS
--------------------------------------------------------------------------------

Using gsutil:
  # Upload to main bucket
  gsutil cp myfile.txt gs://BUCKET_NAME/
  gsutil cp -r my-directory/ gs://BUCKET_NAME/folder/

  # Upload to landing bucket
  gsutil cp myfile.txt gs://LANDING_BUCKET_NAME/
  gsutil cp -r my-directory/ gs://LANDING_BUCKET_NAME/folder/

Using gcloud storage:
  # Upload to main bucket
  gcloud storage cp myfile.txt gs://BUCKET_NAME/
  gcloud storage cp -r my-directory/ gs://BUCKET_NAME/folder/

  # Upload to landing bucket
  gcloud storage cp myfile.txt gs://LANDING_BUCKET_NAME/
  gcloud storage cp -r my-directory/ gs://LANDING_BUCKET_NAME/folder/

--------------------------------------------------------------------------------
3. DOWNLOAD FILES FROM BUCKETS
--------------------------------------------------------------------------------

Using gsutil:
  # Download from main bucket
  gsutil cp gs://BUCKET_NAME/myfile.txt ./
  gsutil cp -r gs://BUCKET_NAME/folder/ ./my-directory/

  # Download from landing bucket
  gsutil cp gs://LANDING_BUCKET_NAME/myfile.txt ./
  gsutil cp -r gs://LANDING_BUCKET_NAME/folder/ ./my-directory/

Using gcloud storage:
  # Download from main bucket
  gcloud storage cp gs://BUCKET_NAME/myfile.txt ./
  gcloud storage cp -r gs://BUCKET_NAME/folder/ ./my-directory/

  # Download from landing bucket
  gcloud storage cp gs://LANDING_BUCKET_NAME/myfile.txt ./
  gcloud storage cp -r gs://LANDING_BUCKET_NAME/folder/ ./my-directory/

--------------------------------------------------------------------------------
4. COPY FILES BETWEEN BUCKETS
--------------------------------------------------------------------------------

Using gsutil:
  # Copy from landing bucket to main bucket
  gsutil cp gs://LANDING_BUCKET_NAME/myfile.txt gs://BUCKET_NAME/

  # Copy entire directory
  gsutil cp -r gs://LANDING_BUCKET_NAME/folder/ gs://BUCKET_NAME/folder/

Using gcloud storage:
  # Copy from landing bucket to main bucket
  gcloud storage cp gs://LANDING_BUCKET_NAME/myfile.txt gs://BUCKET_NAME/

  # Copy entire directory
  gcloud storage cp -r gs://LANDING_BUCKET_NAME/folder/ gs://BUCKET_NAME/folder/

--------------------------------------------------------------------------------
5. LIST FILES IN BUCKETS
--------------------------------------------------------------------------------

Using gsutil:
  gsutil ls gs://BUCKET_NAME/
  gsutil ls gs://LANDING_BUCKET_NAME/
  gsutil ls -l gs://BUCKET_NAME/  # with details

Using gcloud storage:
  gcloud storage ls gs://BUCKET_NAME/
  gcloud storage ls gs://LANDING_BUCKET_NAME/
  gcloud storage ls -l gs://BUCKET_NAME/

--------------------------------------------------------------------------------
6. VERIFY PERMISSIONS
--------------------------------------------------------------------------------

Test the service account:
  gcloud auth activate-service-account --key-file=./service-account-key.json
  gcloud storage ls gs://BUCKET_NAME/
  gcloud storage ls gs://LANDING_BUCKET_NAME/

Get service account details:
  terraform output service_account_email

Get bucket names:
  terraform output bucket_name
  terraform output landing_bucket_name

--------------------------------------------------------------------------------
7. SECURITY BEST PRACTICES
--------------------------------------------------------------------------------

⚠️  IMPORTANT:
  - NEVER commit service-account-key.json to version control
  - Store keys securely (use secret managers in production)
  - Rotate keys regularly (every 90 days recommended)
  - Use Workload Identity when running on GCP
  - Limit key usage to necessary environments only
  - Delete unused keys immediately

To disable key creation:
  Set in terraform.tfvars:
    create_service_account_key = false

--------------------------------------------------------------------------------
8. EXAMPLE WORKFLOW (LANDING TO MAIN BUCKET)
--------------------------------------------------------------------------------

# 1. Apply terraform
terraform apply

# 2. Set credentials
export GOOGLE_APPLICATION_CREDENTIALS="./service-account-key.json"

# 3. Upload a file to landing bucket
echo "Hello World" > test.txt
gsutil cp test.txt gs://$(terraform output -raw landing_bucket_name)/

# 4. Copy from landing to main bucket (this will trigger Pub/Sub notification!)
gsutil cp gs://$(terraform output -raw landing_bucket_name)/test.txt \
         gs://$(terraform output -raw bucket_name)/

# 5. Download the file from main bucket
gsutil cp gs://$(terraform output -raw bucket_name)/test.txt ./downloaded.txt

# 6. Verify
cat downloaded.txt
